# The Willow Nest Hotel - Static HTML Version

This is a complete static HTML/CSS/JavaScript version of The Willow Nest Hotel website, converted from the original React application.

## ✅ Completed Pages

### Main Pages
- **index.html** - Home page with all 10 sections (Hero slider, Booking widget, Highlights, Facilities, Locations, About preview, Testimonials, Amenities, Offers, Newsletter)
- **location-ibadan.html** - Ibadan location page (81 rooms)
- **location-abuja.html** - Abuja location page (27 rooms)
- **location-ogbomosho.html** - Ogbomosho location page (34 rooms)

- ✅ Same layout and grid systems
- ✅ Same hover effects and transitions
- ✅ Same responsive breakpoints
- ✅ Same booking widget integration
- ✅ Same hero slider functionality

### Key Components
1. **Navigation** - Sticky header with logo, links, and Book Now button
2. **Hero Slider** - Auto-playing image carousel with 6 images
3. **Booking Widget** - Bridging sections with negative margin

## 🚀 Deployment

Simply upload the entire `static-html-version` folder to your web server. The site is fully self-contained with:
- No build process required
- No dependencies
- Pure HTML/CSS/JavaScript
- All assets included
